# Step 2: cell budget + LoD — Implementation Plan

> Executed inline (superpowers:executing-plans), one final review.

**Goal:** Heightmap capped at 4,096 cells per side; ground drawn as 64-cell chunks whose detail drops with distance; debug tints, chunk borders, wireframe and live counts.

**Spec:** `plans/2026-10-31-step2-design.md`

## Global Constraints

- `MAX_CELLS = 4096`, `CHUNK_CELLS = 64`. Detail distance 25–2000 m, step 25, default 150, hasDebug, debugDefault true. Wireframe toggle default off.
- Heights row-major: `heights[iz * samples + ix]`, `samples = cells + 1`, point (ix, iz) at `x = -size/2 + ix·cellSize`, `z = -size/2 + iz·cellSize`.
- Level n covers distances `[D·2^(n-1), D·2^n)` (level 0 below D); step = 2^level cells; max level 6.
- Tests per area only; whole suite once at the end. Commit per task on main.

## Review Focus

1. Map size dragged at the largest sizes: a 67 MB heightmap and thousands of chunks rebuilt per slider tick — rebuild at most once per frame.
2. Cell counts that aren't a multiple of 64 (e.g. 334 cells): edge chunks smaller, last sample exactly at the map edge, no gaps.
3. Saved settings from step 1 (no `detailDistance`, no `wireframe`) load with defaults.
4. Flying far outside the map: every chunk at its coarsest level, nothing breaks.
5. A chunk switching level must free the old geometry (memory steady while flying around).

### Task 1: Cell budget and stored heightmap — `src/world/ground.ts`, `tests/world/ground.test.ts`
- Produces: `MAX_CELLS`; `Ground` gains `samples: number`, `limited: boolean`, `heights: Float32Array`; `heightAt(x, z)` bilinear over `heights`, clamped to the map.
- Tests: `makeGround(4000, 0.25)` → cells 4096, cellSize 0.9765625, limited true, heights length 4097²; `(1000, 0.25)` → 4000 cells, not limited; `(1000, 3)` unchanged from step 1; `heightAt` blends: set heights of one cell's 4 corners, sample its middle → average; outside the map → edge value.

### Task 2: On/off settings — `src/settings/types.ts`, `list.ts`, `store.ts`, `src/ui/toggleRow.ts`, `src/ui/buildMenu.ts`
- Produces: `ToggleSetting { kind: 'toggle'; id; name; tab; section; default: boolean; hasDebug: false; debugDefault: false }`; `Setting = SliderSetting | ToggleSetting`; store `isOn(id): boolean`, `setOn(id, on)`; `get`/`set` throw for toggles and `isOn`/`setOn` for sliders; load type-checks per kind. `interface Row extends Piece { setNote(text: string): void }`; `ToggleRow implements Row` (empty debug column, name, switch `.menu-toggle`); `buildMenu` rows: `Map<string, Row>`. List adds `detailDistance` and `wireframe` in MAP / "Detail".
- Tests: store defaults/save/load/reset for `wireframe`; old saved data without the new ids → defaults; ToggleRow click → `isOn` flips and follows store; MAP page has sections Terrain and Detail.

### Task 3: LoD maths — `src/render/lod.ts`, `src/render/chunkGeometry.ts`, `tests/render/*.test.ts`
- Produces: `CHUNK_CELLS`; `MAX_LEVEL = 6`; `lodLevel(distance, detailDistance): number`; `chunkRanges(cells): { start: number; end: number }[]`; `sampleIndices(start, end, step): number[]` (always includes `end`); `buildChunkGeometry(ground, xr, zr, step): BufferGeometry` (top grid from heights + skirt hanging `max(1, step·cellSize)` m down along all four edges; positions, normals, index).
- Tests: `lodLevel(100,150)=0`, `(150,150)=1`, `(299,150)=1`, `(300,150)=2`, `(1e9,150)=6`; `chunkRanges(334)` → 6 ranges, last `{320, 334}`; `chunkRanges(128)` → 2; `sampleIndices(320, 334, 4)` → `[320,324,328,332,334]`; geometry at step 1 for a 64-cell chunk: 65² top vertices, top triangles 64²·2, every top vertex y = height there, skirt vertices lower than the edge they hang from.

### Task 4: Chunked ground with debug view — `src/render/gridMaterial.ts`, `src/render/terrainView.ts`, `src/render/chunkBorders.ts`, `src/main.ts`; delete `src/render/groundView.ts`
- `makeGridMaterial(shared, tint)`: shared uniform objects `cellSize`, `showGrid`, `tintAmount` plus per-level `tint`.
- `TerrainView(scene)`: `update(ground)`, `setDetailDistance(d)`, `setDebug(on)` (tints + borders), `setWireframe(on)`, `setShowGrid(on)`, `updateLod(cameraPosition)` (per chunk: 3D distance to the chunk's box → level; rebuild + dispose old geometry on change), `chunkCount`. Level tints: `#3fbf3f, #d6d63a, #f0a030, #e8602c, #c8342c, #8e2420, #5a1a18`.
- main: settings changes mark the map dirty; rebuild once per frame when dirty; `updateLod` every frame; notes every 0.5 s: Detail distance "chunks: N · triangles drawn: X" (from `renderer.info.render.triangles`); Cell size note adds "limited to … m at this map size" when limited.
- Verify: tsc, whole suite, browser check (spec's list).
